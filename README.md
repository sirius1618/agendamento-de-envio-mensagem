# agendamento-de-envio-mensagem
> Solução técnica para um desafio de estágio em desenvolvimento backend proposto pela Magalu. O objetivo é construir uma API REST para gerenciar agendamentos de envio de comunicações (e-mail, SMS, push e WhatsApp).

  - **Tecnologias:** TDD, dokcer, REST, springBoot, java 21, postgresql.

# Requisitos do Projeto
- [ ]  `endpoint` que receba uma solicitação de agendamento de envio de comunicação 
	- [ ] Data/Hora para envio
	- [ ] Destinatário 
	- [ ] Mensagem a ser entregue 
- [ ] Salvar no banco de dados a solicitação de envio. 
- [ ] `endpoint` para consultar o estado do agendamento de envio de comunicação 
- [ ] `endpont` para remover um agendamento de envio de comunicação.
